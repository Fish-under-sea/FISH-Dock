# Security Policy

## Supported Versions

The current maintained desktop line is **FISH Dock 1.1.x**. Earlier 1.0.x builds should be upgraded. Business plugins are versioned separately in [FISH-DOCK-Plugins](https://github.com/Fish-under-sea/FISH-DOCK-Plugins).

## Reporting a Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Fish-under-sea/FISH-Dock/security/advisories/new) for reports containing sensitive details. If private reporting is unavailable, open an issue containing only a minimal description and a request for a private contact channel.

Include the affected version, operating system, affected feature and reproducible steps using synthetic data. Do not attach live API keys, GitHub tokens, cookies, mail passwords, identity archives or unredacted logs. Response and release timing depend on maintainer availability.
