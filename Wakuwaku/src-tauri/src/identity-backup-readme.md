# FISH Dock 身份迁移包

> **这是未加密的普通 ZIP。** 包含 OFM 凭据、API Key、LAN Key、EAC 授权及可导出的邮件授权码。请像密码文件一样保管，不要上传到 GitHub、Issue、聊天群或公开网盘。

## 包含哪些资料

| 文件 | 作用 |
| --- | --- |
| `settings.json` | OFM 服务设置、本机 API Key、LAN 开关与 LAN Key |
| `channel-credentials.json` | 与渠道账号关联的 OFM 凭据 |
| `channel-pack/*.json` | 账号索引、模型开关、偏好、必要锁定及已存在的用量账本 |
| `stats.json` | 已存在的 OFM 用量记录；缺失时不伪造 |
| `eac-user.json` | 已存在的 EAC 本地授权 |
| `mail-accounts.json` | 邮件服务器和账号资料 |
| `mail-secrets.json` | 为本包临时解密生成的邮件授权码；不作为运行时密码库 |
| `manifest.json` | 包格式、文件大小、SHA-256、导出时间与缺失凭据数量 |

本包不包含 DSH 凭据库、邮件正文、浏览器资料、设备登录环境、LHM 系统凭据、程序依赖、外观、宠物、缓存、日志或以前的导入备份。SHA-256 能检测损坏，不能证明来源可信。

## 迁移到另一台设备

1. 在目标 Windows 用户下安装兼容的 FISH Dock，保留该设备现有资料。
2. 在 FISH Dock“身份与备份”中选择本 ZIP。预览其格式、账号数量及替换范围。
3. 确认后，应用只停止自身持有的 OFM 服务与邮件轮询，先保存目标身份恢复副本，再成组替换身份。
4. 目标默认身份目录为 `%USERPROFILE%\.fish-dock`；使用 `FISH_DOCK_DATA` 时以设置页显示的实际位置为准。不要复制到程序安装目录或 DSH 的主目录。
5. 邮件密码会在目标当前用户下重新用 DPAPI 加密。不要手动用 `mail-secrets.json` 替换运行时的 `mail-secrets.dpapi`，也不要指望直接复制其他机器的 DPAPI 文件就能解密。
6. 检查账号、模型开关、历史用量和邮件。缺失、过期、已撤销或存在设备绑定的凭据需重新授权；本包不能保证免登录。
7. 检查目标网络与 LAN 开关。包会保留 LAN 设置，但防火墙、IP 地址及路由不会随包迁移。不需要共享时先关闭 LAN。
8. 两台设备会持有相同的本机 API Key 和 LAN Key。需要独立密钥时，在目标设备轮换并更新客户端。

导入执行替换而非账号合并。旧的 OFM-only 包只替换 OFM 范围，不清空邮件。当前完整包才包含并替换邮件身份。

## 回退和缺项

导入前的副本保存在当前身份目录的 `.backups` 中。这些文件也包含秘密，不应共享或再次打进导出包。提交后服务启动失败时，应用尝试恢复本次副本并显示结果；请按界面结果处理，不要反复启动失效账号。

从旧版升级时，原 `%USERPROFILE%\.dsh-fish`、旧邮件配置和原 Windows 邮件凭据会保留。本版本不自动删除它们。回退旧版只使用旧副本，不包含迁移后新增的资料；新旧目录不会自动双向同步。

清单中的缺失凭据数量大于零时，不能将本包视为可直接完成全部授权的备份。导入只能恢复实际存在的资料，无法重建未导出的秘密。

## 导出位置

默认位置取当前用户的系统“下载”目录，可在设置中修改并在原生保存窗口最终确认。取消保存不会写出 ZIP 或临时明文文件。迁移结束后自行妥善处理不再需要的明文副本。
