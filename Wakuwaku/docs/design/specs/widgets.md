# 小工具外观规格（定稿，2026-10-16）

样稿：https://claude.ai/artifact/KM46tLMdCLWnAFSqPfYsbz（只有用户能打开；深色/浅色可切换，任务栏叠放、胶囊里的行、桌面那一摞都能点）。
设计：任务栏模式外观设计会话。用户已确认。

一套小工具用在三个地方：任务栏、胶囊展开、桌面。每个小工具有小 / 中 / 大三档中的一到三档。桌面上可以单独放、叠成一摞、放进「工作台」；任务栏上可以单个放、几个轮播、叠起来点一下向上展开。

---

## 1. 数据：一个小工具要提供什么

- 现有 widget（`{ id, label, value, icon, color, … }`）只够小档。加一个可选的 `detail`，按档取用：
  - `sizes`：它有哪几档，如 `['s','m','l']`、`['s','m']`、`['s']`。
  - `series`：曲线 / 柱子的数据，如 `{ points: number[], unit, hi?, lo? }`。
  - `rows`：列表，如邮件 `[{ from, subject, when }]`、自选股 `[{ code, name, price, change }]`。
  - `extra`：小档下面那一句和中档的补充，如 `'阴 · Dresden'`、`'最高 16° 最低 8°'`。
- 和 main 上已有的字符串 `detail`（a6c715a，最长 24 字，胶囊里接在数值后）兼容：`detail` 是字符串时当作 `extra`，是对象时按上面的字段。现有脚本不用改。
- 上限（防止脚本把岛撑爆）：`series.points` 最多 120 个点；`rows` 最多 12 行；名字类字段 16 字、主题类 60 字、`extra` 24 字，超出用「…」。
- 只给了 label/value 的脚本小工具（examples/widgets/*.ps1）：只有小档；中档自动用「数值在上、名字在下」两行；没有大档。
- 内置的（天气、系统监控、自选股、邮件、Claude 今天、番茄钟、倒计时）按第 4 节给齐。

## 2. 外观语言（深色 / 浅色）

- **材质**：一块玻璃。
  - 深色底 `rgba(28,29,34,.56)`；浅色底 `rgba(250,250,252,.62)`。
  - 后面模糊 30、饱和度 1.6。
  - 四周一圈 1px 细线：深 `rgba(255,255,255,.11)`，浅 `rgba(0,0,0,.07)`。
  - 顶边一道 1px 高光（inset）：深 `rgba(255,255,255,.08)`，浅 `rgba(255,255,255,.7)`。
  - 阴影：深 `0 16px 40px rgba(0,0,0,.32), 0 2px 6px rgba(0,0,0,.2)`，浅 `0 16px 40px rgba(0,0,0,.14), 0 2px 6px rgba(0,0,0,.08)`。
- **光晕**：右上角一点自己颜色的光，`radial-gradient(120% 90% at 100% 0%, <色> 22%, transparent 55%)`。只这一处。
- **桌面上的模糊怎么来**：桌面小工具在桌面那一层，后面只有壁纸。用任务栏云母同样的办法：取那块屏的壁纸，裁出小工具所在的那块，模糊 30、提饱和度，再盖上面的底色；壁纸变了就重取。不用 DWM 亚克力（每个小工具一个原生窗口太重，而且后面只有壁纸）。
- **字**：
  - 大数字：Segoe UI Variable Display 300 字重、等宽数字、字距 −0.03em。小档 46px、中档 34px、大档里的副数 26px。
  - 名称：12px / 600、灰（深 `rgba(235,235,245,.64)`，浅 `rgba(30,30,36,.62)`）。
  - 补充：12.5px 同灰；再次一级 11.5px 更浅（深 `.34`，浅 `.34`）。
  - 一个小工具里最多三层字：名称、主数值、补充。中文用 Microsoft YaHei UI。
- **颜色**：每个小工具一种，只用在图标、进度、光晕上；数字是正文色。
  | 小工具 | 深色 | 浅色 |
  |---|---|---|
  | 天气 | `#8cc8ff` | `#1a78c2` |
  | 系统监控 | `#34d27b` | `#0f7b3f` |
  | 自选股（标题色） | `#ffd36b` | `#a46a00` |
  | 邮件 | `#6fa6ff` | `#0067c0` |
  | Claude 今天 | `#f08a62` | `#c45a2c` |
  | 番茄钟 | `#ff7a6b` | `#c4362b` |
  | 倒计时 | `#b99bff` | `#6b45c7` |
  - 涨 / 跌（语义色，另算）：绿 深 `#34d27b` / 浅 `#0f7b3f`，红 深 `#ff6b6b` / 浅 `#c42b3c`。
    - 谁涨谁跌由插件页股票的「涨跌颜色：红涨绿跌 / 绿涨红跌」决定，全处一致。
    - 没选过时按语言给默认：中文红涨绿跌（现有股票脚本一直是这样），其他语言绿涨红跌。
  - 涨跌小胶囊：高 18、圆角 9、同色 16% 底。
- **图标**：Segoe Fluent Icons。天气 E753（阴）/ E706（晴），系统监控 E950，自选股 E9D9，邮件 E715，番茄钟 E916，倒计时 E787。Claude 今天用她的小头像（14px 圆）。
  - 没有图标的小工具（脚本小工具等）：用名字的第一个字，放在 16px、圆角 4 的小方块里。
    - 底色：它自己颜色的 18%（浅色 14%）。
    - 字：它自己的颜色（浅色用深一级），600。
    - 没有颜色时：底 rgba(127,127,127,.18)，字用次级灰。
    - 用到图标的地方都照这样，不用圆点。

## 3. 尺寸和网格（桌面）

- 网格 72px，缝 12px。
- 小 156×156（2×2），中 324×156（4×2），大 324×324（4×4）。
- 圆角 22，内边距 14 / 16。
- 工作台：圆角 28，内边距 14（标题栏高 46），里面 8 列 × 最多 4 行；里面的块圆角 16。
- 拖动贴网格；离屏幕边至少 24。

## 4. 每个小工具每一档放什么

- **天气**（小·中·大）
  - 小：名称 · 大数 11° · 「阴 · Dresden」 · 「最高 16° 最低 8°」。
  - 中：右上地点 · 大数加「阴 / 8°–16°」 · 下面 6 个整点（时间 / 图标 / 温度）。
  - 大：再加一条全天温度曲线（292×64，1.6px 线、渐变填充、末端圆点） · 7 个整点 · 最下一行明后天。
- **系统监控**（小·中·大）
  - 小：CPU 圆环（58px，线宽 5）里写百分比 · 右边「内存 44%」「↓ 7.4K」。
  - 中：CPU / 内存 / GPU 三列数字 + 4px 进度条 · 下面网络速度 + 一条迷你曲线（110×28）。
  - 大：CPU 大数 + 60 秒曲线（292×70） · 内存 / GPU / 磁盘三行（名称、明细、百分比、进度条） · 最下网络和运行时长。
- **自选股**（小·中·大）
  - 小：第一只的代码、价格（26px）、涨跌胶囊、迷你线。
  - 中：三行：代码 + 名称、迷你线（90×22）、价格、涨跌胶囊。
  - 大：第一只的价格（34px）+ 涨跌 + 成交 · 曲线（292×96） · 「1日 1周 1月 1年」切换 · 最下其余两只。
- **邮件**（小·中·大）
  - 小：未读数（46px）· 「封未读」· 最新一封「Anna：周五见」。
  - 中：右上「13 封未读」· 最新三封（发件人加粗、时间、主题一行）。
  - 大：账号切换（全部 / 各邮箱）· 最新六封。主题属于私密内容（第 8 节）。
- **Claude 今天**（小·中·大）
  - 小：轮数（46px）· 「轮 · 2 小时 01 分」· 「批准 3 次 · 1.7B token」。
  - 中：轮数 / 时长 / token 三个数 · 下面每小时轮次柱子（292×30，当前小时用本色，其余用轨道色）。
  - 大：再加每小时柱子（292×54）+ token 曲线 · 最下「最忙的会话」。
- **番茄钟**（小·中，没有大）
  - 小：圆环（84px）中间剩余时间。
  - 中：圆环（96px）· 今天第几个（圆点）· 「之后休息 5 分钟」· 暂停 / 跳过。
  - 没有大档的理由（写在大小菜单里，灰掉）：「番茄钟只需要一眼看剩下几分钟」。
- **倒计时**（只有小）
  - 小：天数（46px，「天」小一半）· 事件名 · 日期。
  - 想看多个日子就放几个小档叠成一摞。

## 5. 任务栏

- **单个**
  - 小档：16px 白色单色图标 + 数值，高 40，左右内边距 9，悬停底色和其他按钮一样。
  - 中档：数值在上（12px）、名字在下（11.5px 灰），和时钟一样。
  - 大档不上任务栏。
  - 图标白色单色，和托盘一致；只有涨跌这类语义色带颜色。没数据时整格变灰，显示名字。
- **轮播**（几个共用一格）
  - 固定宽度：取成员中档里最宽的。
  - 每 6 秒向上换一个：0.5 秒，`cubic-bezier(.3,1.2,.45,1)`。
  - 右边一列小点（3px，间距 3）：当前那个拉长到 8px、不透明，其余 30%。
  - 鼠标停在上面暂停；滚轮手动翻。
  - 有新内容的（如来信）插队先显示一轮。
- **叠放**（几个叠成一格）
  - 显示最上面那个（中档样子）。顶上露两道细边：上沿下 3px 一道宽 62%、40% 不透明；上沿一道宽 44%、20% 不透明。
  - 点一下，从这一格向上升起一张玻璃卡片：
    - 宽 300，离条带 8px，以这一格为中心，不出屏幕；圆角 16，内边距 10。
    - 标题「叠放的小工具 · N 个 · 拖动排序」。
    - 每个一行（圆角 11、底色同工作台的块）：30px 彩色图标块（本色 15% 底）· 名字 · 一句话 · 右边数值（18px）和单位。
    - 升起 0.32s；行依次晚 40ms。
  - 再点这一格、或点外面就收回。拖动行改顺序，拖出去就拆开。
  - 打开时这一格保持悬停底色。

## 6. 胶囊展开

- 小工具按行排在胶囊里：
  - **小档一行**：13px 图标（本色）· 名字 · 右边数值（本色、半粗）。
  - **中档一行**：两层（名字在上，补充 11px 在下），或右边带迷你曲线（56×16）。
- 有大档的行右边有个 8px 的 › (E76C)。点一下就地展开成整宽卡片（大档的胶囊版）：
  - 圆角 14，内边距 10 / 12，底色深 `rgba(255,255,255,.05)`、浅 `rgba(0,0,0,.035)`。
  - 展开 0.34s；箭头转 90°。
  - 同一时间只展开一张；再点收回。
- 卡片内容是第 4 节大档的精简版，宽度按胶囊内宽。比如天气：大数加一句、温度曲线（约 270×40）、7 个整点。

## 7. 桌面

- **层级**：在桌面那一层，浮在壁纸上、在普通窗口下面。显示桌面（Win+D）后仍然看得见。避开桌面图标：放下时如果盖住图标，向最近的空位挪。
- **单独放**：拖到哪里停在哪里。鼠标移上去，右上角出现两个 24px 按钮：「大小」(E740) 和「更多」(E712)。「更多」里有：移到任务栏、放进工作台、叠放、移除。双击打开详情。
- **叠放**
  - 把一个小工具拖到同样大小的另一个上，停 0.5 秒就叠成一摞。
  - 最上面完整显示；后面两层：下移 13px、缩 0.94、75% 不透明，和下移 25px、缩 0.88、45% 不透明，只露底边、不画内容。
  - 右边外侧一列点（6px 宽，当前 16px 高）。
  - 翻页：滚轮、触控板上下滑、或点右边的点，0.45s：上一张向上滑走淡出，下一张升上来。有新内容的会自动翻到最上面一次。
  - 普通拖动挪整摞（和单个小工具一样），不用时间或距离来区分手势。
  - 拿出一张：菜单「把「X」拿出来」；或把它拖到另一个小工具上组成新的一摞。
- **看不见时不刷新**：那块屏上有最大化或全屏窗口盖住桌面时，桌面小工具不刷新、不读传感器；桌面露出来（或 Win+D）时再读。
- **工作台**
  - 一块更大的玻璃，模糊 40；标题栏左边标题和数量，右边「添加 / 更多 / 折叠」。
  - 里面的小工具不带自己的玻璃和阴影，只是平的块：深 `rgba(255,255,255,.06)`、浅 `rgba(255,255,255,.55)`，细线深 `rgba(255,255,255,.06)`、浅 `rgba(0,0,0,.05)`，光晕降到 55%。
  - 可以折叠成只剩标题栏。整块可拖动。一块屏可以放几块，名字可改，如「工作」「行情」。
  - 补充（2026-10-16，做第三期前）：
    - **玻璃**：和单个小工具同样用壁纸裁切的办法做模糊，只是模糊 40；被盖住时不刷新。
    - **放进去**：拖到工作台上，落到最近的空格；放不下就往下加一行，最多 4 行。满了就不收：工作台边框轻轻抖一下（0.3s），小工具回到原处。
    - **拿出来**：拖出工作台的边，就变回桌面上单独放的；也可以用菜单「拿出工作台」。
    - 工作台里这一版不放叠放：拖一摞进来时，提示「工作台里不能放叠放」并退回。
    - **空的工作台**：里面一个虚线框，写「把小工具拖进来」/ "Drag widgets here"。
    - **折叠**：只剩 46px 的标题栏，标题后面依次排里面小工具的 16px 图标（最多 6 个，多的写「+N」），让人折着也知道里面有什么。
    - **改名**：双击标题；回车确认，Esc 取消。
    - 标题栏按钮「添加」打开小工具库，选中的放进第一个空格。
    - 标题栏常显（不用悬停才出现）；里面每块的「大小 / 更多」照单个小工具，悬停出现。
- **放在哪就在哪**：一个小工具只放在一个地方（任务栏 / 胶囊 / 桌面三选一）。放到桌面或任务栏以后，收起的胶囊右侧不再固定显示它（比如系统监控的读数）；展开后的岛照旧列出所有小工具，作为总览。

## 8. 状态

- **没数据**：变灰，只写名字和「暂无数据」。
- **加载**：数值位置一道微光。
- **出错**：琥珀色图标加一句原因。
- **私密**（邮件主题、金额）：鼠标移上去才显示，平时模糊或用「···」代替。跟现有的「显示具体内容」设置走。

## 9. 动效

- 统一曲线 `cubic-bezier(.3,1.2,.45,1)`。
- 轮播 6s 一换、0.5s；叠放展开 0.32s；桌面翻页 0.45s；卡片展开 0.34s。
- 系统关了动画（prefers-reduced-motion）时：全部改成淡入淡出，轮播不自动换。

## 10. 在哪里管理

- 右键任一小工具（任务栏、胶囊、桌面上都一样）：
  - 大小：小 / 中 / 大。没有的那档灰掉，悬停显示理由。
  - 放到：任务栏 / 胶囊 / 桌面。
  - 叠放 / 拆开；放进工作台。
  - 移除。
- 「插件」页现有的小工具库加一列「放在哪」。拖库里的卡片到桌面，就新建一个单独放的。

## 11. 建议的分期

1. 任务栏的轮播和叠放、胶囊里的行和就地卡片：在现有的任务栏布局和 widgets 上扩展。
2. 桌面上的单独放和叠放：新的桌面层窗口和壁纸模糊。
3. 工作台。

每一期做完交给软件测试会话，截图发给外观设计会话核对。
