# Wakuwaku 设计风格与设计语言

> 2026-10-17 用户确认。这份只定**气质和方向**，不定死具体数值。具体的颜色、圆角、时长写在代码的样式变量里，以代码为准；这里举的数字只是「现在是这样」的例子。
> 以后设计变了，改这份文档的方向描述就行，不用逐条对数字。

---

## 一句话

**像 Windows 11 自己长出来的一层，安静、通透、轻；只有她本人带一点俏皮和温度。**

## 风格关键词

- **贴系统**：看起来是 Windows 的一部分，不像外来的 App。
- **安静**：平时几乎不出声，有事才轻轻提醒。
- **通透**：用玻璃和 Mica 的层次感，不用厚重的色块。
- **轻**：线细、字不粗、动作快，播完就停。
- **有温度**：温度只在她身上：立绘、小动作、心情色、流光。

不要的：花哨的渐变和霓虹光效、厚重的投影、自己发明的控件样式、为了好看一直在动的动画、满屏的颜色。

## 设计语言

### 1. 材质：三层玻璃
层次靠材质区分，不靠颜色：
- **贴着桌面的**：任务栏条带、桌面小工具。用 Mica 或壁纸模糊，透出底下的壁纸色调。
- **浮在上面的**：灵动岛、卡片、菜单、设置面板。用亚克力或半透明磨砂，比底层更实一些。
- **最上层的临时提示**：基本不透明，保证看得清。

在 Windows 10 或者关了透明效果时，一律退回成不透明的同色底，不能透出一片空白。

### 2. 颜色：中性为主，颜色只表达意义
- **底色和文字**：中性灰阶，深浅两套，跟随系统的深浅色。
- **强调色**：跟随你在 Windows 里设置的强调色。按钮、开关、选中状态用它，不自己定品牌色。
- **有意义的颜色**，只在对应的地方出现：
  - **心情色**：做完绿、改好蓝、出错红、在等你琥珀。只用在她的状态、小点、光环上。
  - **小工具自己的颜色**：只出现在它的图标、进度和一点角落光晕上，不铺满整块。
  - **涨跌红绿**：跟随设置。
- **彩色**只在两处：她本人，和流光。别处保持素净。

### 3. 形状：胶囊和圆角卡片
- 基本形是**胶囊或药丸**：灵动岛、任务栏上的她、提示条都是两头全圆。
- 面板和卡片用**大圆角矩形**。同一类东西用同一档圆角，整个界面只用少数几档。
- 桌面上的东西贴着一套**网格**对齐，排得整齐。
- 边框用一根细线加一道淡淡的顶部高光，不用粗边框。

### 4. 字体：跟 Windows 11 一样
- 英文和数字用 **Segoe UI Variable**，中文用 **微软雅黑 UI**。这正是 Windows 11 自己的搭配。
  - 现在代码里有的地方中文字体排在前面，有的地方英文字体排在前面，要统一成英文字体在前、中文跟在后面。
- 大数字（时间、温度、读数）用 Segoe UI Variable Display 的细体，大而轻。
- 字重只用常规和中粗两档，不用粗体堆强调。
- 字号收成少数几档：大数字、标题、正文、小字说明。

### 5. 图标：系统的优先，线性风格
- Windows 已经有的图标（设置、网络、音量、程序图标），直接用系统的：Segoe Fluent Icons 和程序自己的图标。
- 自己画的图标用**细线条**风格，和 Fluent 图标一致。不用实心的大色块图标。
- 没有图标的小工具，用名字的第一个字，放在它自己颜色的淡底小方块里。

### 6. 动效：快、轻、有一点弹性，播完就停
- 动画只用来**表达变化**：展开、收起、到达、提醒。不为装饰而动。
- 展开收起要快，带一点弹性；淡入淡出要短。
- 只有她本人可以动得活泼一些（立绘的小动作、流光）。
- 播完就停，不留一直在转的东西；没人在电脑前时全部停下。
- 系统关了动画时，不转、不移动，改成淡入淡出或者静止亮一下。

### 7. 她的表达
她是整个界面里唯一的「角色」，个性都集中在她身上：
- **立绘和小动作**：开心、皱眉、挥手、睡觉，表达状态。
- **心情色**：她的状态一眼能看出来。
- **流光和小点**：她「有话想说」的方式，不打断你。
- 其他界面不模仿她的可爱，保持系统般的克制。这样她才显得特别。

### 8. 文字的语气
- 像一个靠谱的朋友在旁边说话：口语、简短、直接。
- 按钮用动词开头，比如「连接 Claude Code」「放进工作台」。
- 不客套，不用「请」「成功」，不用感叹号；出错时说清楚怎么了、可以怎么办。
- 中英文各写各的，英文不是中文的直译。
