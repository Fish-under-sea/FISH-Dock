# FISH Dock 1.2.2

发行版本：`v1.2.2`。主程序、Tauri 元数据、Cargo 锁文件与安装器统一为 `1.2.2`；插件保持独立版本。

## 修复：插件页的「自启动」开关点不动

1.2.1 给插件页加了 `host.autostart` 接口，但**页面桥按设计拒绝 `host.` 与 `plugin.` 开头的方法**（`extension-page.js` 里那条校验把这两类名字留给插件后端）。于是插件页调用 `host.autostart` 时消息被直接丢弃：既不成功也不报错，前端 Promise 一直挂着，开关停在禁用状态——看起来就是「点不动」。

本版把宿主侧接口改名为 **`dock.autostart`**，走同一套逻辑（读 `Installed.autostart`、写回注册表），并保留 `host.autostart` 作为别名兼容。插件页面同步改用 `dock.autostart` 后：

- 打开网关页即可读到当前状态，点击立即生效，失败会回滚勾选并在页面上报错；
- 宿主早于 1.2.2 时开关自动隐藏（旧桥会丢弃 `dock.` 以外的命名空间，用它只会静默失败）。

同一批发布里 Magpie 1.1.1 与 Clash 1.0.4 都已改用新接口。

## 其余

本版只动这一处宿主代码与版本号，认证、备份、插件安装、更新检查的行为与 1.2.1 相同。1.2.1 的完整说明见 [release-1.2.1.md](release-1.2.1.md)。

## 安装

- `FISH-Dock-Setup-1.2.2.exe`：首装或修复。
- `FISH-Dock-Update-1.2.2.exe`：精简更新包，适用于基础资源完整的 1.2.1 安装。
- 同版本 `SHA256SUMS.txt` 一并发布。

安装包不改动 `%USERPROFILE%\.fish-dock` 里的凭据与配置，升级后登录与已装插件都保持原样。
