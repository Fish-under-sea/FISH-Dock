# FISH Dock 1.2.1

发行版本：`v1.2.1`。主程序、Tauri 元数据、Cargo 锁文件与安装器统一为 `1.2.1`；插件保持独立版本，不随宿主升级。

本次是修复版，重点在「掉登录」与「备份不完整」两件事，另外合入两个社区 PR。

## GitHub 登录：认证一次，之后长期有效

- **凭据不再因版本变化读不出来**：凭据记录加 `schema_version` 并去掉字段严格校验，旧记录照旧能读；读不懂时另存 `github-access.dpapi.bak`，不再直接丢弃。
- **失效分级**：只有 GitHub 明确回 `bad_refresh_token` / `expired_token` / `invalid_grant` 才清凭据；网络失败、限流、边缘节点 401 一律保留会话。
- **启动复核**：每次启动（含更新到新版本之后）后台自动续期并复核身份与主仓 Star，不必等用户点插件；失败只停在「待复核」。
- **Star 回执 7 天**：一次联网核验管一周，离线不把官方插件锁死。
- **接受长期令牌**：应用关掉「令牌过期」后签发的是不带 `expires_in`、不带 `refresh_token` 的令牌，现在照收（`expires_at` 记 0，视为永不过期）并清掉不再需要的刷新凭据；仍带 8 小时有效期却缺刷新令牌才算异常。

## 配置备份：只带凭据与名册，导入不再被版本卡住

- **运行态不进包**：`trash`、`routing`、用量日志、模型与市场缓存、`*.bak`、`*.tgz`、`dist`、`node_modules` 统一排除。
- **邮件正文不入包**（`host/mail-store`）；邮件账号名册与登录凭据照常带走。
- **解不开的凭据原样带走**：别的用户或别的机器留下的 DPAPI 不再让整包导出失败，按 `opaque` 编码带走并计入「需重新登录」数。
- **导入放宽**：只要求 `data_schema` 相等，插件版本升级过也能恢复，目标机器已装的版本号保持不变；不再用备份里的旧 `host/storage.json` 覆盖宿主版本。
- `missingCredentials` 回真实值，不再固定为 0。

## 插件

- **自启动开关（宿主侧）**：`Installed.autostart` 持久化，启动恢复只看 `enabled && autostart`；插件页可通过 `host.autostart` 读写。插件页面上的那个开关要等插件重新打包发布后才出现，安排见仓库外待办。
- **认证只约束官方插件**：安装、启用、页面与扩展调用改用 `require_plugin`，GitHub 与主仓 Star 只对 `fish.feishu` / `fish.clash` / `fish.magpie` / `fish.ofm` 生效；第三方插件不受这条约束。
- **第三方插件（新）**：插件中心新增「第三方插件」页，「官方商店」改名「官方插件」。按 npm 包名检索公开 registry 并安装；包需含 `plugin.json` 与 `README.md`，声明摘要逐一比对，按第三方命名空间登记，与官方插件共用安装事务、备份与回滚。

## 社区 PR

- #14 灵动岛窗口铺满工作区：窗口宽度恒为工作区宽、左上角固定，中/右锚点切换宽窄页不再横移重绘。
- #15 连接判断与账单分账：设置快照改用完整渠道列表（ZCode、DSH、Reasonix 不再被误判未连接）；token 组件新增 ZCode / OpenCode / DSH 三份账，与「今天」卡同步翻页。合入后修掉 `selAgent` 在两块之间互相重置的缺陷，并把 DSH 解析抽成生产与单测共用的一份。

## 安装

- `FISH-Dock-Setup-1.2.1.exe`：首装或修复，覆盖安装会保留数据根与已装插件。
- `FISH-Dock-Update-1.2.1.exe`：精简更新包，适用于基础资源完整的已有安装。
- 同版本 `SHA256SUMS.txt` 一并发布，下载后请核对。

两份安装包都不改动 `%USERPROFILE%\.fish-dock` 里的凭据与配置；升级后原有 GitHub 登录继续有效。
