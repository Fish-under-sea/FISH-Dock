# FISH Dock 1.1.0

## 本版

- 新增独立插件平台和官方商店，飞书、Clash、Magpie、OFM 通过独立包分发，桌面安装器不预装业务插件。
- Windhawk 1.7.3 引擎及 LLVM-MinGW 编译器随安装包交付，支持模组源码／集合导入、开关和备份恢复。
- Magpie 管理页、模型网关、嵌入代理分别分配回环端口，修复默认端口占用导致的启动失败；保留原生管理界面。
- OFM 和 Magpie 使用较大管理视图；飞书、Clash 支持单／双栏。
- 标签支持排序、横向滚轮与鼠标拖动；修复美化卡片间距和字体布局。
- 移除插件页自动置顶／锁定，以及全屏事件自动覆盖手动偏好的逻辑。
- 关闭时保存当前标签，重开后恢复；手动锁定／置顶保持原值，插件异步加载后的标签恢复不覆盖新选择。
- 官方插件要求 GitHub 登录与主仓 Star 双条件验证；验证码在打开系统浏览器前自动复制，按服务端间隔轮询授权结果。验证取消、关闭或超时后释放临时焦点。
- 应用层安装／卸载和身份确认采用内部异步弹窗；新安装插件默认启用，服务凭据和参数仍需配置。
- 修复全屏退出后的窗口恢复；主动唤醒和待处理审批可在其他应用全屏期间显示，不永久改写锁定／置顶偏好。
- 插件和「关于」提供检查更新；卡片不重复，按数值版本比较避免降级提示，包体积自动使用 KB／MB／GB。官方目录增加 GitHub API 回退与经校验缓存。
- 运行时发现支持显式路径与便携目录，旧安装路径仅作兼容回退。选择性移植 Wakuwaku v0.3.6 的 WebView 缩放命中和 Explorer 交接，保留 FISH Dock 插件协议；未引入上游商店、自动更新协议或 DSH token 统计。
- 清理主仓旧 OFM 源码副本、暂存脚本与未编译模块；保留原始许可证、身份迁移兼容和独立插件 SDK。
- 合并主仓期间新增的独立修复：通知补全仓库与工作区上下文、今日统计按模型分别计数并支持横向切换、截图覆盖层不触发全屏隐藏、全屏与 Explorer 重启期间避免误判任务栏争用。旧内置飞书／Clash／Magpie 入口继续由独立插件替代。

## 安装资源

Windows x64；Node 24.14.0；固定版 WebView2 155.0.4283.62；Windhawk 1.7.3。官方输入摘要由 runtime-sources.json 固定。安装资源共 10,513 个文件，展开约 1.39 GB，安装包使用 NSIS 压缩。安装包未做 Authenticode 签名。

## 验证说明

前端、SDK 与构建脚本合并回归 333 项通过（其中前端行为 304 项）。Rust 桌面环境完整回归为 529 项通过、13 项忽略，另有 2 项既有 LHM 环境检查失败：受限目录 ACL（Windows 错误 5）和 Task Scheduler 根目录（0x80070003）；未将其标为通过。排除这两项环境检查的重复回归全部通过。正式版保留既有编译警告。安装器另以真实离线 makensis 编译验证。

真实 Windows 验收已覆盖：设备码复制与读取比对、浏览器打开、验证临时焦点取消恢复、全屏时主动唤醒、全屏时合成审批显示及拒绝回复、全屏退出自动恢复。GitHub 设备流程申请已成功；真实账号登录、Star 和网页授权仍由用户确认，测试未代用户批准第三方授权。

插件 ZIP 使用 deflate、UTF-8 文件名、CRC32 和逐资源 SHA-256。早期正式实例内存采样：应用私有内存约 20.3 MB，WebView2 约 55.0 MB，4 个插件 Node 进程约 25.0、23.4、27.7、24.1 MB；该数据不是本轮长期内存基准，空闲插件服务按需启动。

插件及商店目录在单独的 FISH-DOCK-Plugins 仓库发布，桌面宿主与 SDK 在本仓发布。
