# FISH Dock 1.0.2

本版同步完整 Dock 与内置 OFM 源码，集中修复 WorkBuddy、邮件操作、窗口状态和账号续期，并统一各厂商界面。

> **Meoo 目前仅属于灰度测试，暂时不可使用。** 本仓库保留其界面、授权及协议实验代码；隔离测试通过不代表已开放真实账号登录、项目绑定或模型调用。

## 主要更新

- **WorkBuddy**：透明验证区分暂时故障与鉴权失败，408、429、5xx 不再持久锁停；保留诊断、手动恢复和旧暂时故障状态迁移。
- **邮件**：增加当前邮箱及聚合邮箱「全部已读」。按固定未读 UID 快照分批处理，每批最多 200 个，校验 UIDVALIDITY，仅增加 Seen、保留其他标志。确认成功后更新缓存，部分失败返回准确数量；窄窗口下筛选可见，操作有忙态和结果反馈。
- **窗口**：进入 OFM 默认锁定并置顶，离开顶级标签或关闭时解除；本次手动关闭后保留用户选择。其他应用全屏时，在 Dock 内询问保持或取消两者；已关闭置顶但仍锁定时，连续全屏 2 秒后自动解除锁定，并隔离迟到回复及过期计时。
- **账号与余额**：查询前按账号续期，合并并发请求，隔离单账号故障。空池启动后新增账号也进入续期调度。保留 1.0.1 的 CodeArts 专用签名传输、出口隔离、严格模型测试、持久测试结果及手动／自动探测顺序。
- **每日积分**：商汤增加「一键领取」，先查当日正数 daily_grant 账单，未确认时续期再查。以实际到账确认成功，不写死金额；若仍未到账，提示完成官网当日登录后重试。
- **总览**：今日积分核验按厂商折叠，默认收起；账号文字缩小 3 px、字重 400，分别显示今日已领和当前余额，证据不足时显示待确认。
- **界面与品牌**：14 个渠道统一厂商卡片、图标、账号／模型折叠区和「添加账号」文案，按渠道已有能力保留功能；Qoder 区分国际版与国内版。桌面、安装器、托盘、通知及网页使用指定原始角色图标。
- **源码**：完整提交 Rust / Tauri 桌面、OFM 服务与 React 前端、渠道源码及构建产物、测试和安装脚本，保留上游来源及许可。

厂商入口顺序：WorkBuddy 国内版、WorkBuddy 国际版、TRAE、Cline、CodeArts、LobsterAI、Loomy、Raccoon、Meoo、MiniMax Code、Qoder 国际版、Qoder 国内版、ZCode、Gemini。入口数量不等于实际可用渠道数量。

## 安装与数据保留

从 [v1.0.2 Release](https://github.com/Fish-under-sea/FISH-Dock/releases/tag/v1.0.2) 下载安装器与 SHA-256 校验文件。先从托盘退出旧 FISH Dock，并退出单独运行的 OFM，再沿用原安装目录直接更新。

- 身份目录仍为 `%USERPROFILE%\.fish-dock`，沿用 `FISH_DOCK_DATA` 和旧 `DSH_FISH_DATA` 覆盖值。
- 保留账号 ID、credentialRef 与密钥索引关系；旧 `.dsh-fish` 仅在新目录缺失时复制校验，原件保留。
- Dock 设置与 WebView 数据仍在 `%LOCALAPPDATA%\DSH-FISH`；邮件密码沿用 Windows DPAPI。
- 完整身份 ZIP、替换前恢复副本及旧 OFM ZIP 导入保留邮件的机制继续保留；卸载保留用户数据。

公开源码及安装包不包含 Google OAuth 默认客户端参数。使用 Gemini OAuth 前，请自行设置 `CMDC_PAK_GOOGLE_CLIENT_ID` 和 `CMDC_PAK_GOOGLE_CLIENT_SECRET`，并在相同环境启动服务。

安装器未进行 Authenticode 签名。下载文件大小和摘要以 Release 附件为准；此前同名本地测试包不是本次公开构建产物。

## 验证记录

本次发布前完成：

- 公开文档及本地引用、源码配置和 OAuth 参数排除检查。
- 原生全屏状态机、邮件批量已读、锁定生命周期和品牌定向回归；Windows Release 主程序已编译。
- CodeArts 专用传输 12 项与多上下文 RPC 7 项，出口回归 92/92，真实渠道 worker 集成 15/15。
- WorkBuddy 验证、严格模型测试及手动结果、续期调度、Meoo 与商汤协议定向回归，前端类型检查和最终 UI 构建。
- 真实构建页面的 14 个厂商详情、授权弹窗、取消及错误恢复、账号／模型折叠和今日积分核验；320、375、414、768、1280 五种视口。厂商请求使用隔离 RPC 替身。
- 发布资源清单：2,206 个文件、814,041,841 字节，清单和 SHA-256 校验通过。
- 包内 Node.js 24.14.0：管理页、未登录管理 401、渠道 RPC、429 后继续调用、备份和重启保留密钥／设置；合成邮件文件字节不变。该测试没有使用真实账号，NODE_PATH 为空。

全量历史回归中保留的环境限制和忽略项不计为本轮通过。Windows 实际全屏切换、真实邮箱、服务商账号授权和跨日到账仍需实机验证；商汤续期不保证触发每个账号当天发放。Meoo 仍按上方灰度状态说明处理。
