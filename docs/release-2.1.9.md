# FISH Dock 2.1.9

本版只升级 Dock 宿主，插件版本不变。纳入 [#76](https://github.com/Fish-under-sea/FISH-Dock/issues/76) / [#77](https://github.com/Fish-under-sea/FISH-Dock/pull/77) 的子灵动岛文件暂存与原生拖放，以及 [#78](https://github.com/Fish-under-sea/FISH-Dock/issues/78) 的系统 Evergreen WebView2 改造。

## 子灵动岛：文件暂存与原生拖放

- 子灵动岛支持文件暂存与原生拖放落点，将文件交互接入桌面岛。
- 统一新增 Win32 窗口句柄声明与调用方式，消除本次引入的 9 条外部函数声明冲突警告。

## WebView2 改由系统提供

- 不再随安装包分发固定版 WebView2、固定版许可文件与相关 ACL 处理逻辑；宿主使用系统 Evergreen WebView2 Runtime。
- **Setup 在安装开始前检测依赖**：检查当前用户与系统的 64/32 位注册表记录，并确认对应运行时程序存在。缺失时询问是否打开 [微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/)，随后中止安装，不自动下载或安装依赖；静默模式缺失时也以非零码退出。
- **Update 自身不检测、不提示、不安装 WebView2**。升级前请确认系统 Evergreen 已安装且可用；旧安装目录中的固定版不再作为新版运行时。
- 应用启动时不增加 WebView2 依赖检测或提示，也不再弹出旧固定版许可确认。
- Node.js 24.14.0 仍随包提供。资源清单继续使用 schema 2，新清单不再写 `webview2_version`，宿主仍兼容旧清单。

## 旧安装清理与数据保留

- Setup 覆盖安装与 Update 都按安装归属清单清理旧随包 WebView2、固定版许可等不再属于新包的文件，兼容旧资源清单迁移路径。
- 清理属于安装事务：旧文件先移入事务备份，安装成功后再提交；安装失败则恢复旧安装。遇到旧运行时文件被占用，不会跳过删除后谎报成功，而是让本次事务失败并回滚。
- **保留用户资料与配置**，包括 `%LOCALAPPDATA%/FISH Dock/webview`；不做用户数据目录的全量删除。

- 安装器常规回归：54/54 通过；2.1.9 清理与回滚专项：4/4 通过，覆盖旧归属清单、旧资源清单、提交失败和旧运行时文件占用。
- Rust 运行时筛选测试：40 通过、0 失败、4 忽略；包含 21 个实际 runtime 测试，其余来自同名筛选命中的 plugin_runtime 模块。`cargo check` 与全部目标检查通过。
- 已核对 NSIS 展开脚本与真实系统注册表；一次性安装初始化验证确认：缺失运行时则安装前退出，存在则继续。
