# FISH Dock 1.2.0

发行版本：`v1.2.0`。完整安装包与精简更新包均包含 GitHub 登录保持修复。主程序、Tauri 元数据、Cargo 锁文件、运行资源清单和安装器统一为 `1.2.0`；插件保持独立版本。

## 本次同版本修订

本次按用户要求修订并替换 `v1.2.0` 同名双包和校验文件：修正应用内旧标语、正式安装版误显示源码运行、API 返回 403 时检查失败。安装版支持手动及自动检查，API 不可用时回退同仓官方 Release 页面。保留整包升级模式，不替换单独 EXE。此前已下载的同名包需要重新下载并比对本次校验值；同版本修订不依赖版本号自动提醒。

## 安装与更新

- 覆盖安装使用受管文件清单与可恢复事务，清理已废弃且确认归属的旧文件，保留用户配置及插件资料。
- 发行文件暂存在目标安装卷，流式 SHA-256 校验后优先移动；跨卷复制重新验证副本。
- 重复校验复用绑定清单与安装目录的文件校验记录；文件标识、大小、修改时间或状态时间变化时重新校验。运行时未变化时避免重复递归授权。
- 提供完整离线安装包与精简更新包。精简包复用已有且经过校验的基础资源；缺失或损坏时要求完整安装包修复。
- 安装过程显示分阶段进度，修复 Windows PowerShell 5.1 读取 UTF-8 无 BOM 中文脚本时的解析错误。

## 配置与运行时

- 「FISH Dock 配置与备份」覆盖宿主设置、布局、插件注册及各命名空间的持久配置、凭据、名册与密钥。
- 恢复前预览并备份，校验失败不提交，激活失败回滚整个恢复范围，中断后启动恢复。
- 保留旧备份格式兼容。普通 ZIP 含明文凭据；本机加密资料按支持格式迁移后重新加密。缓存、临时文件、可重新下载的程序包与历史备份排除在整仓备份之外。
- 改进开发版与发行版 Node.js 24 发现策略，展示实际来源、路径与版本，失效覆盖值可回退。正式版继续携带 Node 与固定版 WebView2。

## 登录与界面

- 修复 GitHub 设备登录未保存刷新令牌的问题：续期凭据由宿主加密保存，访问令牌到期前自动轮换；临时断网、限流或 Star 复核失败保留账号资料。
- 区分「登录失效」与「Star 待复核」，自动复核 Star，并保留官方插件的登录及 Star 双条件门控。旧版本未保存刷新令牌的账号，需要重新登录一次才能建立续期记录。
- 验证码复制结果使用明显的 Dock 内弹窗，支持再次复制、打开验证页、取消与手动解除临时锁定。
- 临时锁定时左侧或中间的灵动岛移到右侧；结束验证或手动解除后恢复原位置，不覆盖长期偏好。
- 弹窗宽度和高度收紧，长内容内部滚动，移除重阴影与整视口暗色遮罩，保留模态焦点和 Escape 焦点恢复。
- 已恢复配置但缺少插件程序包时提供重新安装入口，原配置保留。

## 验证与边界

- 前端、SDK、浏览器与安装工具完整回归：367 项通过。
- 更新检查：正式 `installed` 模式无账号凭据实测成功读取官方 `v1.2.0`；API 403 回退、来源校验和安装模式行为回归均通过。
- GitHub 登录专项：15 项后端测试通过，覆盖刷新轮换、重启、临时断网、限流、明确失效与旧账号格式。
- Rust 正式安装模式全量：556 项通过、14 项忽略、2 项既有 LHM 本机环境失败（目录 ACL 权限与计划任务根目录 `0x80070003`），不标记为全量通过。
- GitHub 令牌到期与网络失败用合成凭据及可控响应复现；未声称真实账号连续 8 小时长时验收已完成。
