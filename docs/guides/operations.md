# 安装、网络与配置迁移

本文承接旧 `app/README` 中不应随入口精简而丢失的操作与排障知识。版本下载与当前变更以[仓库首页](../../README.md)为准；源码构建见[开发指南](DEVELOPMENT.md)，安装器参数见[构建说明](installer-build.md)。

## 安装与异常排查

- 面向 Windows 10/11 x64；系统任务栏集成主要面向 Windows 11，第三方任务栏组合需要单独验证。
- 从官方 Release 取得 Setup 并核对同名 `.exe.sha256`。升级前从托盘完全退出旧版及其子进程；已有安装沿用登记目录，不自动搬迁。首次默认目录为 `%LOCALAPPDATA%/Programs/FISH Dock`。
- Setup 携带 Node.js，使用系统 Evergreen WebView2；没有运行时会提示官方下载页并中止。Windhawk 和业务插件由用户另行安装，不随宿主包分发。
- 安装器未进行 Authenticode 代码签名。未知发布者与 SmartScreen 提示不能靠改名、自绘图标或自签名可靠消除；不要关闭系统防护、导入不明根证书或绕过组织策略。
- `Error writing temporary file. Make sure your temp folder is valid.` 是 NSIS 执行安装脚本前的临时目录错误。检查临时目录、权限、磁盘空间与安全软件日志，不把它当作插件配置错误。
- 覆盖安装出现 DLL 写入失败时，先确认旧版与子进程已退出；不要忽略写入错误继续安装。
- 卸载只移除自身安装文件与登记，保留用户数据；只清理确认属于本安装的自启动任务。手动删数据前先导出备份。

## 首次使用与身份验证

首次默认任务栏，可在设置或托盘切换灵动岛、边缘与位置。重启保留偏好；保存的显示器不可用时回退主屏。开启减少动态效果后使用短淡入。

插件页的 GitHub 设备授权由宿主执行，令牌经 DPAPI 加密存放于配置仓 `host/keys`，不交给业务插件。更新不应清除登录；启动时复核身份与主仓 Star，离线为待复核，不应直接删除凭据。自建 OAuth 应用可通过 `FISH_DOCK_GITHUB_CLIENT_ID` 指定 Client ID，不能把真实令牌写入源码或环境说明。

设备码与复制结果以 Dock 弹窗为准；网页确认后自动检查。等待期间可以取消验证或手动解除临时锁定。安装完成默认启用插件，但模型服务仍需在插件页面配置并启动。API 监听地址、端口及 Key 以插件实际页面为准，不把历史示例端口当作固定契约。

Agent、邮件和第三方插件需要各自的客户端、账号与权限。安装宿主不会授予上游服务资格；「本地」也不意味着离线模型推理或免费额度。

## 局域网访问

1. 在所装模型插件自己的管理界面启用 LAN，共享仅用于可信网络。
2. 复制页面显示的当前设备地址与独立 LAN API Key。远端客户端不能使用 `127.0.0.1`，也不能拿本机 Key 替代 LAN Key。
3. 在另一设备配置兼容客户端。轮换后旧 Key 立即失效，所有客户端都需同步。
4. 不用时关闭。端口占用或网卡变化时关闭后重新开启，以成功绑定并显示的地址为准。

管理页面仍仅允许本机访问；同端口不意味着管理接口开放到所有地址。HTTP 传输不应映射公网。程序不自动创建防火墙规则，跨设备可达性还受防火墙、AP 隔离和系统规则影响，不能仅凭本机监听测试宣称联调成功。

## 配置与凭据迁移

使用「通用 → FISH Dock 配置与备份」，不再使用退役 OFM 专项包。默认导出到数据根下 `host/exports`，可更改。

- 包含宿主设置、布局、插件注册与各命名空间的持久配置、凭据、名册和密钥。
- 邮件正文 `host/mail-store` 不入包；账号名册与登录凭据仍保留。
- 排除运行态记录（如 `trash`、`routing`、用量日志、模型与市场缓存）、缓存、临时文件、可下载程序包和历史备份。
- ZIP 含明文凭据，按密码文件保管。导入后重新进行本机加密；无法解开的旧凭据需在目标机器重新登录，不能因此把整次迁移标为无条件成功。

导入时保持 Dock 打开。宿主暂停自己的模型服务与邮件同步，先预览再确认，保留恢复前副本，失败尝试事务回滚。旧包按其原有范围处理，不自动扩大恢复范围。

旧 `%USERPROFILE%/.dsh-fish` 复制迁移到 `%USERPROFILE%/.fish-dock` 时不删除原目录；已有新目录优先，不自动合并。当前数据根按 `--data-root`、`FISH_DOCK_HOME`、用户目录下 `.fish-dock` 依次解析。内部程序名、应用标识与卸载登记保留兼容，不代表界面名称未更新。

## 反馈与安全

提供系统和应用版本、停靠模式、复现步骤及脱敏日志。不要公开真实密钥、完整 Cookies、私人邮件或备份 ZIP；截图同样要检查身份信息。漏洞报告不附可用凭据。
