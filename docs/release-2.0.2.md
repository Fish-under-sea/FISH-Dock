# FISH Dock 2.0.2

补丁版。宿主为 **2.0.2**，兼容 **插件 2.1.x**（插件 2.1.2 稍后单独发布）；不是「宿主与插件同版本」，
安装时请按各自的版本号对待。

这一版不引入新功能，只修插件的三件事：**看不见**（失败没有日志）、**查不到**（错误只剩一句兜底话术）、
**停不掉**（残留内核被当成自己的进程杀错）。逐条对应到来源 issue。

## 插件诊断（#53 / T01–T03）

- **stderr 不再被丢弃**：插件进程的 `stderr` 从 `Stdio::null()` 改为管道接管，逐行写到
  `host/plugin-logs/<插件 id>.log`；单文件 1 MB、保留 2 份滚动，写入前过统一脱敏（令牌、路径、
  邮箱、IP、主机名），单行截断 300 字符。写入失败只丢这一行，不盖掉原始错误。
- **失败可查**：`host/plugin-failures.log` 每行一条 JSON，含插件 id、版本、失败阶段、退出码、
  时间、原始错误与对应日志路径；宿主重启后仍可查。
- **错误带定位**：插件卡的 `error` 文本改为「原始原因 + 退出码 + 日志路径」，
  并新增结构化字段 `failure` / `exitCode` / `logPath`；无退出码时说的是「无响应（握手超时）」，
  不冒充「已退出」。
- **日志入口**：插件卡新增「打开插件日志」，直接打开 `host/plugin-logs/`。
- 日志目录不在整仓备份范围内（`config_backup` 不收），备份体积不因此增长。

## 运行态与标签页（#14 宿主侧 / T04–T05）

- **运行态判据**：`running()` 从「进程存活」改为「进程存活 + 握手可应答」——发一次 `host.hello`，
  任何编号匹配的应答都算活着（2 秒超时、正结果缓存 2 秒）。进程还在但事件循环卡死时不再判为运行中。
- **残留内核回收**：按 pid + 实际启动时刻（±5 秒）+ 控制器可达三重判定，只回收「连不上控制器」的
  僵尸内核，能连上的留给插件 attach；不根据持久化 pid 结束外部程序。
- **标签页不再消失**：插件页标签的显示条件从「插件正在运行」改为「已安装 + 已启用 + 已解锁」。
  插件进程退出后标签页仍在，点进去显示错误态（原因 + 「启动」+「打开插件日志」），启动后当场恢复。
  这修的是「退出再进 Dock，Clash 标签页没了」这类现象。

## 错误码透传（#14 / T12）

- 插件侧抛出的业务错误不再被折成一句通用文案。三处折叠已打通：`sdk/node/plugin.mjs` 的命令包装、
  宿主 `plugin_protocol::answer()`、插件页 `sdk/browser/bridge.js`。
- 页面按 `code` 查表显示专属文案（含「下一步做什么」），未知码才落到唯一的「未识别错误」。
- 兼容旧行为：`publicServiceError` 仍返回字符串（`gateway.mjs` 依赖）；业务错误不再被当成致命错误
  停掉插件进程（`is_business_error(&error) || error == OPERATION_ERROR`）。

## 版本位

- `Cargo.toml`、`tauri.conf.json`、`Cargo.lock` 与安装器 `--version` 统一为 **2.0.2**。
  漏掉 `Cargo.lock` 时 `cargo check --locked` 会直接报 `cannot update the lock file`，本版一并修正。

## 已知限制

- 真实 mihomo 内核的 attach / 停止、真实 Windows 注册表读写路径、3 秒 attach 冷却的真机手感，
  均未在本轮自动化里覆盖，属 G1（双插件自启高压测试）与 G2（成包校验）的范围。
- Clash 侧部分启动失败的 `operationError` 仍是固定文案（例如端口冲突时页面显示「启动失败，请检查
  内核路径、端口和订阅缓存」而不是精确码）。可归因信息在同一次启动的插件日志里；精确码化列入
  下一版候选，不算本版缺陷。

## 安装

- `FISH-Dock-Setup-2.0.2.exe`（约 312 MB）：首次安装、资源缺失或修复安装。
- `FISH-Dock-Update-2.0.2.exe`（约 30 MB）：已有版本且基础资源完整时使用，只含本次变更。
- 两个包都附同名 `.sha256`，另有 `SHA256SUMS.txt` 汇总；安装包当前未做 Authenticode 签名。
