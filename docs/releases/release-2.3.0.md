# FISH Dock 2.3.0

> **已被 2.3.4 替代**：本文件是 2.3.0 的旧发行说明草案，保留为历史输入；2.3.4 的发行说明见 `docs/releases/release-2.3.4.md`。2.3.0 只覆盖安全 + dialogs + host.dock 路由，2.3.4 在此之上补齐 #88 全项、#89 与上游全量。
>
> **草案（2026-11-15）**：修复与能力尚未实现，数字与包名待出包后核对；本文不构成已发布说明。

2.3.0 修掉一个本地端口的安全问题，补上一个插件长期缺的宿主能力，并修正插件后端调用 `host.dock.*` 一律失败的旧缺陷。主岛的外观、布局和动画没有改动。

只发布 Setup 完整安装包，与 2.2.1 起的口径一致。

## 安全修复

**网页不能再往 FISH Dock 的本地端口发请求。** 以前任意一个打开着的网页都能用简单跨源请求让她退出、弹出伪造的确认面板、塞进假的会话和插件；通过 DNS rebinding 还能读到 `/health`；开着排障开关时，网页还能在页面里执行代码。

现在，除 `/v1/*` 外：

- 带网页来源的请求（`Origin` 是 `http:`、`https:`、`file:` 或 `null`）一律 403；
- `Host` 不是 `127.0.0.1` / `localhost` / `[::1]` 的请求一律 403（DNS rebinding 就靠这一条挡住）；
- 不带 `Origin` 的脚本、命令行工具和 agent hook 照常；Thunderbird 扩展照常；`/v1` 保持自己的 Host / Origin / Bearer 校验。

被拒绝的请求会在日志里留一行（每种只记一次，最多 8 种），不会静默。影响版本按代码看从 1.0.0 起；本轮实测 2.2.3。感谢提供复现包的研究者。

## 插件宿主能力：选择文件夹

插件清单新能力 `dialogs`，Node SDK 新方法：

```js
const { dir } = await context.dialogs.chooseFolder({ title: '选择备份文件夹' })
// 取消时 dir 为 null，不抛错
```

- 只有声明了 `dialogs` 的后端能调用；页面侧不提供，插件不能用它绕开页面沙箱。
- 弹出 Windows 自己的文件夹选择框，挂在主岛窗口上；只选目录，不选文件，也不接受插件传入的路径。
- 一次只允许一个对话框，重复调用得到明确的「忙」错误。
- 对话框可能开很久，SDK 对这个方法不设 5 秒超时；用户关闭后才返回。
- 适合「网页模式下没有路径输入框」的插件：插件侧把选中的目录写回自己的配置即可。

插件仓的 magpie「选文件夹」按钮会在插件侧接入后生效；本版只提供宿主能力，不改插件行为。

## 修复

- **插件后端调用 `host.dock.*` 一律回 `HOST_OPERATION_FAILED`**：后端分派只认 `host.windows.*` / `host.fileDrop.*`，`host.dock.*` 落进了存储分支。现在按窗口、对话框、存储三类分派，`dock.rect()`、`dock.onEvent()` 等后端接口可用（#88 的 P3）。

## 兼容性

- 没有声明 `dialogs` 的插件行为不变；已有清单不需要改。要用新能力的插件必须在新版本清单里声明 `dialogs`，旧版本不会自动获得。
- 安全修复只拒绝网页来源；Claude Code / Codex / Antigravity / ZCode / Reasonix / DSH 的 hook、脚本、`curl`、PowerShell 与 Thunderbird 扩展都不受影响。
- `/v1/*` 的协议与鉴权不变。
- 没有数据迁移，没有新的常驻进程，没有安装器结构变化。

## 测试

- 新增安全判据与原始 TCP 管线用例：六种网页来源、五种被拒请求、`/v1` 放行、被拒 POST 正文未读时同连接下一请求仍正常。
- 新增 `dialogs` 的能力、参数、互斥与延迟响应用例；SDK 侧验证超过 5 秒仍能返回。
- 新增 `host_call` 分派单测，钉住 `host.dock.*` 与 `host.dialogs.*`。
- 全量 `cargo test` 与页面测试的结果在出包前填入；环境性失败沿用 2.2.3 的清单，不冒充通过。

## 升级建议

所有用户建议升级，尤其是：经常在浏览器里打开不明页面、开着 `FISH_DOCK_DEBUG=1` 排障、或使用 magpie 网页模式插件的用户。升级前退出正在运行的 FISH Dock；安装包未签名，SmartScreen 拦下时按「更多信息 → 仍要运行」。
