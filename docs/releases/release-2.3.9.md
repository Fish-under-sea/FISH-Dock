# FISH Dock 2.3.9

2.3.9 重构了灵动岛的外观系统，并带来宠物删除、「顶栏 + Dock」测试版，以及一批设置页修复。

只发布 Setup 完整安装包，与 2.2.1 起一致。

## 新增与改进

- **三态主题：** 设置页「外观」顶部新增全宽三态光学胶囊（浅色 / 深色 / 玻璃），支持点击、拖动与甩动切换，随模式连续过渡。玻璃模式提供液态玻璃分区调节；不是玻璃模式时，「液态玻璃」卡片自动隐藏。
- **背景图片：** 可选自己的图片铺在 Dock 面板之后，并调节遮挡。点击缩略图会弹出预览窗：默认按图片比例自动构图（竖图自动偏上），也可以拖动、滚轮缩放（100% 至 250%），或用预设与滑块自行调整，「恢复自适应」一键回到默认。
- **玻璃色调与字体颜色：** 新增紧凑的浮窗调色盘（色板、色相条、RGB、HEX、清除）。标题、正文、次要文字可分别着色，并同步给插件。
- **外观页重排：** 显示方式一排三列，主题模式置顶，「灵动岛外观」拆成独立卡片并默认展开，小工具卡片与「运行依赖」样式对齐。
- **「顶栏 + Dock」（测试版）：** 实时枚举运行中的窗口与图标，Dock 居中并避开 Windows 任务栏。
- **宠物删除：** 已下载的宠物可在设置里删除；Codex 自带和源码内置的宠物不可删。
- **上游同步：** 选择性同步上游 v0.4.3 的 A 类更新。

## 修复

- 收起「小工具」卡片时，不再连带收起「显示」「在终端里用」「自己写一个」。
- 插件「更多」菜单（含「卸载」）被遮挡，以及点击穿透到下层卡片。
- 选择背景图片后不显示：补齐资源协议白名单、缓存刷新与图层显隐。
- 标签页排序拖拽、配置备份的玻璃样式、运行依赖折叠卡等细节。
- 新发布的第三方社区插件被 npm 拆词淹没，以及短名检索问题。
- Antigravity 效率模式默认自动放行普通命令与极速透传，并修复审批弹窗裁切卡顿。

## 测试

- PR #97 的 CI 全部通过：Node 页面与 SDK 测试、README 引用与版本一致性、Rust 单测。
