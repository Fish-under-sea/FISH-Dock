# FISH Dock 2.0.1 预览版怎么用

预览版是**独立的一份程序**，和已安装的 FISH Dock 完全隔离：不装进系统、不覆盖已装版本、不碰你的用户数据、不改注册表与任务计划。看完了直接把目录删掉就能清干净。

## 启动

双击 `启动-2.0.1-预览.cmd`，或在终端里：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File "dist\portable-2.0.1\preview-start.ps1"
```

启动后终端会打印 **PID / 端口 / 数据根**，并等到实例就绪（最多等 60 秒），就绪时输出：

```
就绪：ready.island=True ready.pet=True
```

只想看它准备做什么、不启动：

```powershell
pwsh -NoProfile -File "dist\portable-2.0.1\preview-start.ps1" -WhatIf
```

`-WhatIf` 只打印，不启动、不写任何文件。

## 端口

从 **48101** 起自动找第一个空闲端口（脚本会跳过已装实例的 47213、旧预览的 47413、上一批预留的 47901）。实际用的端口启动时打印出来，也可以在数据根的 `preview.pid` 同目录看到运行信息。

## 数据根在哪

```
build\review-home\
├─ data\host\        程序数据（config、credentials、crashes、plugins…）
│   ├─ config\config.json    配置（display=island 已写死并校验）
│   └─ recent.log            日志
├─ home\             程序的应用目录
└─ preview.pid       本脚本启动的那个 PID（-Stop 用它）
```

这是新目录，与旧批的 `build\portable-home` 无关。**整个 `build\review-home` 删掉就等于重置预览环境**，不会影响已装版本。

## 怎么退出

两种方式，任选：

1. 托盘图标 → 退出（和正式版一样）。
2. 命令行：

```powershell
pwsh -NoProfile -File "dist\portable-2.0.1\preview-start.ps1" -Stop
```

`-Stop` **只结束本脚本自己启动的那个 PID**（记录在 `build\review-home\preview.pid`），并且会先核对那个进程确实是本预览目录里的 `FISH-Dock.exe`；不是就拒绝结束——**绝不按进程名杀**，免得误杀你已安装的正式实例。

没有 `preview.pid` 时 `-Stop` 什么也不做（直接退出 0）。

## 日志在哪

```
build\review-home\data\host\recent.log        当前日志（256 KB 轮转）
build\review-home\data\host\recent.old.log    上一份
build\review-home\data\host\crashes\          崩溃与卡死记录
```

启动失败时，脚本会自动把 `recent.log` 的最后 20 行打出来，并以非 0 退出。

## 出问题怎么收集

把这四样一起发过来就够了：

1. `build\review-home\data\host\recent.log`（和同目录的 `recent.old.log`，如果有）
2. `build\review-home\data\host\crashes\` 整个目录（有崩溃或卡死时才会有内容）
3. 终端里启动脚本打印的那几行（PID / 端口 / 数据根 / 就绪结果）
4. 出问题的截图 + 大概时间点（日志按时间能对上）

打包一条命令：

```powershell
Compress-Archive -Path build\review-home\data\host\recent*.log, build\review-home\data\host\crashes -DestinationPath build\review\logs-$(Get-Date -Format yyyyMMdd-HHmm).zip -Force
```

## 已知边界

- 预览版**不会接管任务栏**：脚本启动前读回配置，`display` 不是 `island` 就拒绝启动并打印原因；`islandHideUnder` 也被强制为 `false`（不躲在别的窗口下面）。
- 预览版不查更新（`autoUpdateCheck=false`），不弹首次引导（`onboarded=true`）。
- 重复运行脚本不会覆盖你改过的设置，只补齐缺的键；`display` 与 `islandHideUnder` 是例外（预览硬要求）。
