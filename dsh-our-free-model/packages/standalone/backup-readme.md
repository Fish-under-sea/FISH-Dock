# FISH Dock · OFM 配置与凭据迁移

> **此 ZIP 未加密，包含明文账号凭据、EAC 授权、本机 API Key 和 LAN Key。**
> 请像密码文件一样保管，仅在可信设备之间传输，不要上传到 GitHub、Issue、聊天群或公开网盘。迁移完成后及时清理不再需要的明文副本。

## 包含范围

本包只包含 OFM 本地服务资料，不包含邮件账号、邮件密码、DSH 凭据库、桌面外观、宠物、WebView2 登录资料、日志、缓存或调用统计。

| 文件 | 用途 |
| --- | --- |
| `settings.json` | OFM 服务配置、本机 API Key、LAN 开关与独立 LAN Key |
| `channel-credentials.json` | 账号索引引用的 OFM 凭据 |
| `channel-pack/state.json` | OFM 账号索引、渠道次序和模型开关 |
| `channel-pack/permanent-locks.json` | 渠道永久锁定偏好 |
| `channel-pack/accounts-backup.json` | 兼容账号快照，运行时不会自动导入该文件 |
| `eac-user.json`（可选） | 导出时已有的 EAC 授权 |
| `manifest.json` | 文件大小、SHA-256、格式版本和缺失凭据数量 |
| `README.md` | 本固定迁移说明 |

## 在 FISH Dock 1.0.1 中导入

1. 先保留目标设备的现有资料。打开「通用 → 身份与备份」。
2. 选择本 ZIP 并查看预览，核对账号数量、缺失凭据和替换范围。
3. 明确确认后才替换 OFM 白名单资料。**OFM 专用包不会改动邮件账号或邮件密码。**
4. 导入前的副本保留在当前身份目录的 `.backups` 中。提交或服务激活失败时，程序会尝试恢复原身份并报告结果。
5. 导入后核对账号、模型开关、EAC、API Key 和 LAN 设置。已过期、已撤销或绑定设备的授权仍需重新登录。

要迁移邮件、OFM 调用统计和 Token 账本，请改用「通用 → 身份与备份」的**完整身份导出**。该入口默认使用 Windows 当前用户的系统「下载」目录，保存目录可以编辑；取消对话框不会写入文件。

## 数据位置与兼容

FISH Dock 1.0.1 的默认身份目录为 `%USERPROFILE%\.fish-dock`。显式设置 `FISH_DOCK_DATA` 时以该绝对路径为准；旧 `DSH_FISH_DATA` 仅保留过渡兼容。旧 `%USERPROFILE%\.dsh-fish` 数据由桌面端复制、校验后迁移，原目录保留；两目录同时存在时使用新目录，不自动合并。

独立 OFM 命令行仍使用其 `OFM_HOME` 或原有默认目录，不能据此推断 FISH Dock 桌面端的目录。请以桌面「身份与备份」实际显示的位置为准。不要把身份资料放进安装目录、WebView2 目录或 DSH 的主目录。

若需人工恢复到兼容旧版，先完全退出两端服务并备份目标目录，再只替换表中的运行文件。`README.md`、`manifest.json` 和额外账号快照不需要复制到运行目录；此操作是替换，不是合并。不要向旧运行目录复制完整身份包里的明文邮件密码。

## LAN 与校验

- 本包保留 LAN 开关、服务端口和两类 API Key。首次启用前确认目标网络可信；不需要共享时关闭 `standaloneLanEnabled`。
- 防火墙、设备地址和路由不会随本包迁移。LAN Key 仅用于推理，不授予管理接口权限。
- 如果两台设备不应共用密钥，请在目标设备分别轮换本机 API Key 和 LAN Key，并更新客户端。
- SHA-256 清单用于检查传输损坏，**不代表数字签名或可信来源**。缺少 EAC 或凭据不能由本包自动补齐。
