# FISH Dock 2.2.3

2.2.3 补齐外部原生窗口 Hook 的最后四项能力（[#87](https://github.com/Fish-under-sea/FISH-Dock/issues/87)），并修掉一个会让整张插件表失效的升级故障。**主岛的外观、布局与动画仍然没有任何改动。**

只发布 Setup 完整安装包，与 2.2.1 / 2.2.2 一致。

## 修复

- **旧插件清单里的退役字段会让整张注册表读不出来。** 2.1.x 的清单带 `islandSub` / `islandPanel`，2.2.0 删掉子岛后它们成了「未知字段」；注册表是一条 JSON，`deny_unknown_fields` 因此让**整张表**反序列化失败，表现是「插件安装注册表损坏」、插件列表为空、所有插件都不启动（Clash 不跑 → 7895 不通，还会连带看起来像网络故障）。
  - 现在这两个字段被明确容忍（读进来丢掉，不写回），其余拼错的字段仍报错。
  - 注册表改成**逐条读**：某一条读不出来只跳过它并记一行日志，其余条目照常工作。韧性保证到「一条坏不影响其他条」。
- **插件停用时没有清掉它的主岛订阅。** 订阅残留会让「按需上报」的计数永远不回落，主岛页面一直被要求逐帧上报。现在停用/卸载/换版时一并清掉。
- **主岛页面在订阅之后才建起来时会错过开关通知。** Dock 刚启动时就是这样：插件先订阅，主岛页后到，于是它从不知道要上报。现在页面就绪时按当前订阅数补发一次。

## 新增

### B4 · 透明区点击穿透

```js
await FishDock.windows.open({
  key: 'ball', page: 'main', width: 200, height: 120, transparent: true,
  hitTest: 'opaque',
  hitRects: [[12, 12, 36, 36]],   // 页面逻辑像素 x,y,w,h
})
```

只有 `hitRects` 覆盖的区域接住鼠标，其余像素穿透到下面的主岛或桌面。运行中可以 `windows.update(handle, {hitRects:[...]})` 随时更新（内容变了、chip 增减）。

- `hitTest: 'opaque'` 必须同时给 `hitRects`，否则拒绝——既不猜「整窗可点」，也不让窗口变成点不到。
- 没写这两个字段的窗口行为与 2.2.2 完全一致，且不登记任何规则（宿主那段轮询一次都不跑）。
- 与 B1 的关系：窗口下限已经降到 32×32，多数形态用不上它；它是「大窗口装小内容」那条路。

### B3 · 把文件拖回资源管理器

```js
// 在插件窗口里按下并拖动某个文件项时
await FishDock.windows.beginDragOut(handle, ['C:/Users/me/report.docx'])
```

宿主用系统 OLE `DoDragDrop` 把文件作为 `CF_HDROP` 交给资源管理器，用户松手即完成一次普通文件拖放（可复制、可移动到别的文件夹）。立即返回，会话在宿主线程里跑到用户松手为止。

- 只接受**本插件自己的窗口句柄**，跨插件句柄在这里过不去。
- 路径必须是存在、绝对、且总量在限内；一次最多 512 项。
- 同时只允许一次会话：插件循环调用不会堆出无数线程。

### D2 · 打开内部插件页

```js
await FishDock.dock.openPage('main')   // 或 context.dock.openPage('main')
```

请 Dock 在**设置面板里**打开本插件已登记的页（`pages[].id`）。这是「设置里的那一页」，不是再开一个外部窗口——旧产物的「+」按钮要的就是它。

- 页面 ID 必须是本插件登记过的；已停用的插件不给开（打开了也只是「插件未运行」）。
- 主岛不在可点时会把设置临时升起来，用户这一下不会白点。

### E4 · 滑出动画期间跟手

收起/唤醒的滑出是页面内的 CSS `transform`，主岛窗口本身不移动，所以光靠 `anchorChanged` 跟不到胶囊。现在动画那一小段里页面逐帧上报胶囊外框，`dock.onEvent` 的 `geometry` 事件跟着逐帧推。

- 只在动画期间（约 320ms）上报，之后交还宿主自己的算法。
- 上报带时效：超过 1 秒的旧值一律不采用——页面崩溃或被系统暂停时 `requestAnimationFrame` 会停，胶囊不能永远停在某一帧上。
- 页面重建时清空，不把崩溃前的值带给新页面。

## 兼容性

- 新增字段全部可选，缺省行为与 2.2.2 一致。
- 已有接口没有改语义，只增不删。

## 内部重构

这一版把主岛订阅、窗口命中、拖出三件事从 `plugin_window.rs` 里拆了出来，各自一个模块：

| 模块 | 职责 |
| --- | --- |
| `plugin_window.rs` | 窗口开、关、位置、拖入路由 |
| `plugin_dock.rs` | 主岛快照、订阅表、几何/指针事件分发 |
| `plugin_hit.rs` | 插件窗口的鼠标命中与穿透 |
| `plugin_drag.rs` | 把文件交给系统拖放 |

`plugin_window` 仍然只向主岛**读取**矩形，没有任何写回；`plugin_hit` 只对插件窗口调 `set_ignore_cursor_events`，不碰主岛的穿透逻辑（那是 `pointer.rs` 的事）。

## 测试

- `cargo test`：**946 passed / 1 failed / 24 ignored**。
- 唯一失败是 `lhm_setup::tests::a_folder_made_with_her_dacl_is_closed_to_the_user`，属沙箱 DACL 环境限制（本轮未改动该模块），不是产品缺陷。
- 新增 27 条验收单测，覆盖：注册表退役字段容忍与条目级容错、主岛订阅的按需启用与清理、命中区域的各类边界（窗口外、未量测、多块）、拖出的路径校验、胶囊快照的两矩形分离与过期判断。
