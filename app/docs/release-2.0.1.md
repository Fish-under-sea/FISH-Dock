# FISH Dock 2.0.1

维护版。宿主为 **2.0.1**，兼容 **插件 2.1.x**（插件仓已到 2.1.0）；不是「宿主与插件同版本」，
安装时请按各自的版本号对待。本版按用户能感知的变化整理，逐条对应到来源 issue。

## 设置页与公告（#39）

- 公告**有内容时**也提供「刷新」入口，不再只在空状态才给。
- 打开「关于」页超过 5 分钟后自动重新获取一次公告（原来只有一小时门）。
- 公告标题不再重复版本号（Release 名自带版本号时去重显示）。

## 全局快捷键（新能力，#45）

- 设置页新增「全局快捷键」录制节：为动作录入组合键。
- 组合键**被其他程序占用**时给出提示；30 秒内未录到可用组合就放弃，不静默挂起。

## 插件平台（#37 / #38）

- 更新 / 卸载改为**事务**：中断可续做，校验不过回滚，失败不阻断其它操作（#37）。
- 回滚点可选择性导出；更新成功后**旧版本目录清零**，只留当前激活版本（#37）。
- 卸载**彻底**：清掉安装载荷与注册，但**保留用户配置**，不误删数据（#37）。
- 插件**自启动**在 Dock 运行中拨开关**即时生效**；`resume()` 失败不再整批静默跳过（#38）。

## 窗口与任务栏、显示（#48 P2 / #43 / #44 / #47）

- **无标题窗口**也会出现在任务栏（不再因没有标题被漏掉）（#48 P2）。
- **托盘图标点击**可到达自身（左键/右键都有响应）（#48 P2）。
- **右键菜单精简**：她的菜单只说关于她的事，任务栏自己的项（任务管理器、Windows 设置等）
  留在条带自身的右键菜单，不重复（#48 P2）。
- **工作区自愈**：换显示器或改缩放后，最大化窗口不再停在条带上方；副屏条带移动不误改主屏（#43）。
- **文字 110% 叠加显示缩放**时，任务栏部件不再上浮、卡片画面不再偏小错位；任务栏按 Windows
  同厚度呈现（#44）。
- **Codex**：失败命令计为失败；「Approve for me」交还 Codex 处理（#47）。

## 崩溃（#40 / #41）

- **卡死抓栈**：界面卡死时抓取调用栈写到 `crashes/hang-<pid>.txt`（#40）。
- **WebView2 被外部结束**不再被误报为崩溃；只有真正的崩溃才记（#41）。

## 网络韧性（#42）

- Wi-Fi 没有出口时读取瞬时为空不再中断（同形加固，#42）。说明：本仓是同形加固，
  **不是**「修复了一个闪退」——避免把它读成上游那条独立故障。

## 商店与模型能力

- **OFM 本地模型正式下架**：商店目录与宿主三处白名单同步移除；**已装用户不受影响**，
  仍可正常启用/卸载（商店目录调整，依用户要求，无单条 issue）。
- **模型能力由 Magpie 插件提供**：关于页与 README 的致谢同步更新，不再把模型能力记在
  OFM / Our Free Model 名下（文案调整，依用户要求，无单条 issue）。

## 明确不包含（转 2.1.0）

- **agy 岛上审批**：整链约 +848 行，未纳入 2.0.1，转 2.1.0（见 issue #51）。
- **内存账 #29 / #30**：内存长跑与 GPU 归因转 2.1.0。

## 兼容性

- 宿主 **2.0.1** 与 **插件 2.1.x** 配套；插件版本号高于宿主，属正常。
- 双包：`FISH-Dock-Setup-2.0.1.exe`（完整安装/修复，190 MB）与
  `FISH-Dock-Update-2.0.1.exe`（已有安装且基础资源完整时只下载变更，31 MB）。
- 数据目录、注册表身份等沿用 2.0.0 的约定，本版不再迁移。
