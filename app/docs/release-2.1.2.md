# FISH Dock 2.1.2

2.1.1 之后的补丁版：把安装包瘦了一大圈，并把 Dock 内部弹窗的观感、安装器的选项做正。

## 这一版改了什么

### 安装包瘦身：不再内置 Windhawk 引擎与编译器（#73）

`resources/windhawk/` 整棵移除——原始 **557.8 MB / 8413 个文件**，占安装资源的 42%，其中 `Compiler/`（LLVM-MinGW）一项就 543 MB / 8394 个文件。

| 口径 | 2.1.1 | 2.1.2 |
| --- | --- | --- |
| 安装资源（解压） | 1328.4 MB / 10513 文件 | **808.0 MB / 2100 文件** |
| 启动必需项 | 14 项（其中 10 项 `windhawk/*`） | **4 项** |
| 安装清单记录 | 10517 条 | 约 2100 条 |

**外观 → Windows 美化不再是「随包自带引擎」**，改为连接你自己安装的 Windhawk（配置里的路径 → 注册表 → `Program Files` 三档探测，顺序与 2.1.0 一致）。导入模组源码、编译、启停、回滚、集合导入这些功能都还在，编译器用你所选那份 Windhawk 自带的。没装 Windhawk 时外观页会明确说「未检测到 Windhawk」并给出指定目录的入口，不再出现「内置引擎尚未就绪，请刷新重试」。

顺带收掉一项许可负担：Windhawk 是 GPLv3、编译器是 Apache-2.0（LLVM 例外），2.1.1 及更早随包分发这些二进制却没在 `licenses/NOTICE.txt` 里写明来源；现在不再分发，义务随用户自己安装的那份走。

> **升级注意**：如果 2.1.1 及更早版本里有用内置引擎**已经启用**的 mod，先用外观页把它们停用再升级——被目标进程映射的 `Engine/*.dll` 在升级时删不掉，会留下一个删不掉的 `resources/windhawk/` 残壳。装完 `resources/windhawk/` 应当不存在。

### 弹窗的视觉居中（#74）

几何居中（弹窗中心 == 面板内容区中心，≤2px）在 2.0.0 就做到了，这一版补的是**看起来**也居中：

- 上下留白从四边等宽 14px 改成 **16 / 12**：标题 16px 粗体压在上方、按钮组沉在底部，等宽内衬会让整个内容块的重心偏上；上多下少把它压回中心。
- 按钮组从贴右下（`flex-end`）改成**水平居中**——实心按钮面积大，贴右下时内容块的视觉重心横向偏右 42px，这是「看着不居中」的主要来源。
- 卡片补一层轻投影（原来是 `box-shadow: none`），卡片中心与面板中心重合这件事才看得出来。遮罩仍然保持透明：设置面板窗口铺满整个工作区宽度，压暗会读成全屏模态。
- `scrollbar-gutter: stable both-edges`：长文案出现滚动条时内容中心不再横向跳（实测前后位移 0.00px）。
- 入场 160ms 淡入 + `scale(.98→1)`，`transform-origin` 固定在卡片中心，三帧中心漂移 0.00px。

顺手修了一个由此暴露的旧缺陷：`dialog-anchor.js` 用 `getBoundingClientRect().height` 量弹窗高度，而入场动画的 `transform` 会让它返回**缩放后**的尺寸（少 2%），按它设 `height` 就内容溢出、滚动条常驻。改用 `offsetHeight`（不吃 transform）。

### 安装包 / 更新包的可选项（#75）

- 桌面快捷方式变成可选：安装界面新增组件页，**安装包默认勾选**、**更新包默认不勾**（老用户桌面上通常已经有了，不重复建、也不覆盖你换过图标的那个）。
- 安装时把选择记进注册表（`DesktopShortcut`），卸载只删自己建的那次；你自己建的同名快捷方式不再被卸载顺手删掉。
- 完成页「启动 FISH Dock」在**两个包里都默认勾选**（原来默认不勾），标题按包区分「已完成安装 / 已完成更新」。
- 静默安装跟着默认值走：`Setup /S` 建快捷方式，`Update /S` 不建。

### 仓库机制

- issue 立项规则落库：`.github/CONTRIBUTING.md` + `.github/ISSUE_TEMPLATE/issue.yml`（查重、类型标签、是否维护者、**版本用 Milestone 表达**、侧边栏六项自查）；崩溃模板补同一套必答项。

## 包与校验

- `FISH-Dock-Setup-2.1.2.exe`（完整安装包）
- `FISH-Dock-Update-2.1.2.exe`（精简差分包，**只对 2.1.1 有效**）
- 各自附 `.sha256`；`SHA256SUMS.txt` 列出全部。

## 已知限制

- 便携版入口仍无载荷（发行不提供便携 exe），安装版不受影响。
- 应用内更新只认 `FISH-Dock-Update-<版本>.exe` 与它的 `.sha256`；跨版本用精简包会缺文件，请用完整安装包。
