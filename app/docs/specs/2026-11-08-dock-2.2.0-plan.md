## 1. 已批准需求（不可因交接缩减）

- 处理 PR #77：https://github.com/Fish-under-sea/FISH-Dock/pull/77 。提供通用 Hook，让第三方插件控制 Dock 进程创建、位于主 Dock 外部的第二个原生 Tauri/WebView2 窗口（独立 HWND）。插件绘制业务页面，宿主仅提供容器、权限、生命周期和拖放路由。设置面板内部插件页是另一种独立模式。
- 移除宿主硬编码暂存 UI、常驻小球、虚构命中扩窗和固定文件管理插件调用。无插件主动请求时不创建隐藏窗口或拦截拖入。
- 浏览器及后端 SDK 均提供 windows/fileDrop；所有权由可信会话推导，校验能力、摘要、代次、票据和句柄，文件路径只交付目标插件。
- 用户再次明确：第三方调用 Hook，由 Dock 产生外部原生第二窗口，插件绘制业务界面；无插件请求时不创建、不绘制、不预建隐藏 WebView。Hook 官方文档同步到 https://github.com/Fish-under-sea/FISH-DOCK-Plugins 的 docs/developers，并从开发者指南直达。
- 2.2.0 是最后一个双包版本：Setup + baseline 2.1.0 的 Update，分别附 `.sha256`。这是让现有旧宿主能升级的过渡资产。
