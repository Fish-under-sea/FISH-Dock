# FISH Dock 2.1.5

2.1.4 的回退版：**外观页的 Windhawk 设置面回来了**，2.1.4 删掉它之后 Dock 打不开。

## 为什么有这一版

2.1.4 除了修代理和插件回退，还顺手把外观页的 Windhawk 设置面整个删了（`windhawk-panel.js`、`index.html` 的脚本引用、`settings.js` 的四处处挂载、`settings.css` 的 22 行样式）。结果是装完打不开——这一版把这部分**原样恢复成 2.1.3 的形态**，其它改动不动。

复查结论：我这边没能复现出具体的启动失败栈（沙箱里 GUI 一起就退，抓不到 panic），所以不再猜原因，直接回滚这块改动。用户实测 2.1.3 正常，恢复后应与 2.1.3 一致。

## 这一版保留了什么（2.1.4 的另外两项）

### 挂了节点却还是走镜像、装得慢

`proxy::ways` 原来是 `(Via::System, Some(系统代理)) if !env_proxy => 系统代理优先`：只要进程环境里残留一个 `HTTP(S)_PROXY`（已经关掉的内核地址、别处写进去的值），就跳过 Windows 系统代理、只让 ureq 按环境变量走。内核一关那条值就指向死端口 → 主源连不上 → 回退镜像。

现在系统代理优先、环境变量只做 `Default` 兜底；`manual` / `none` 与本机回环（`127.*`、`localhost`）不变。

### 插件下载失败的回退不再降级

`#68` 的回退候选只按版本新→旧试，不看本机已装版本：用户已升到 2.2.x、目录最新版暂时下不到时，会一路退到内置表里还能下载的最老一版。现在 `version_candidates` 加了 `floor`，`local_version()` 从 `installed-plugins.json` 读当前版本，低于它的回退候选一律跳过；读注册表失败不拦着装。

## 包与校验

| 包 | 体积 | 说明 |
| --- | --- | --- |
| `FISH-Dock-Setup-2.1.5.exe` | 245.80 MB | 完整安装包（全量资源，Node + 固定版 WebView2） |
| `FISH-Dock-Update-2.1.5.exe` | 29.75 MB | 精简差分包，只含相对 **2.1.4** 的变更 |

- 各自附 `.sha256`；`SHA256SUMS.txt` 列出全部。
- 精简包只对 2.1.4 有效；2.1.3 及更早请用 Setup 覆盖安装（数据在 `%LOCALAPPDATA%\FISH Dock`，安装器不碰）。

## 已知限制

- 便携版入口仍无载荷（发行不提供便携 exe），安装版不受影响。
- 应用内更新只认 `FISH-Dock-Update-<版本>.exe` 与它的 `.sha256`。
